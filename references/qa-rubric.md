# 每日一签验收与回退

## 1. 放行原则

质检不是证明流程已经完成，而是判断作品能否交付。脚本负责结构和可观察不变量；人负责文字、图像与关系判断。

优先级固定为：

1. 内容与出处准确。
2. 原句核心含义没有被改写。
3. 图文关联成立，且符合本系列隐喻表达边界；可感知与表达适配必须同时成立。
4. 中文正文清楚且为第一信息层级。
5. 情绪、媒介和近期差异适配。

前项失败不能被后项分数抵消。

## 2. 内容硬门槛

以下任一失败，返回内容阶段：

- 日期与星期正确。
- 从零创作已重建全历史索引并通过选题广度闸门。
- 胜出项已通过全历史原句与近似版本查重。
- 原文、作者、作品、译者和文本类型准确。
- 摘要、作者谈作品和译文没有冒充作品原句。
- 选定句子在上下文中没有被反转原意。
- 所有复用都有用户明确授权。
- 新创作的 `content_selection.author_review` 已完成，作者与选中项一致，来源、实际检索和边界可回读，结论为 `pass`；不能用查重通过或文学成就代替作者使用适宜性判断。

schema 1.4 不再要求内容总分；用来源证据、候选比较和硬门槛决定，旧记录的分数仅用于历史解释。

## 3. 白话锚点与概念竞争

生成前必须确认：

- `plain_brief.core_meaning` 是唯一核心解释。
- 已启用句意依据合同时，`meaning_basis` 有可回读上下文摘录、归属、支持关系与解释边界；逐字引用正确不能替代句意核验。
- `selected_emphasis` 来自允许的编辑重点，没有制造新含义。
- 核心解释、重点与语义不变量未把执行者联想或人物言论冒充作者立场；画面转译仍承接准确句意，不是只承接新增生活建议。“不冲突”不能充当原文支持。
- `semantic_invariant` 只约束原文关系，未提前指定颜色、物体或额外剧情；记录了常见误读。
- 标准模式至少有三套完整视觉概念。
- 三套方案不是同一抽象隐喻只换材质，至少有两种表达机制。
- 每套概念有 `metaphor_bridge` 与表达准入；直接演示、空泛装饰和难以实现的关系不能凭易懂／无人物而进入决选。
- 只有一套概念被选中，已准入且胜出理由是相对比较。
- 定向模式有明确指定视觉机制的用户指令；纯局部排版修订继承既有概念，不为形式重建定向方案。
- 近期差异没有压过语义清晰度。

不要再对艺术方向设置一套可抵消硬伤的总分。概念竞争和语义冷审就是艺术方向放行条件。

## 4. 执行闸门

生成后检查（默认完整带字卡片；本地路线为排版前底图）：

- 关键动作或状态是否真正出现。
- 画面是否执行了胜出概念，而不只是出现指定媒介。
- 主导关系是否清楚到可以继续排版。
- 文字安全区是否真实可用。
- 生成后发现与生成前计划已经分开。

判定只有：

- `pass`
- `regenerate_same_concept`

若问题来自概念本身，直接返回概念竞争，不在执行闸门里反复润色提示词。

## 5. 排版硬门槛

- 默认图文一体已给准确文案与简短专业设计指引，让模型自主文字设计，未暗加字体、字号、坐标、对齐或行数限制；不要求本地双小样。本地路线才比较两种真实小样并确定性排字。
- 生产模式、生成原件与审查协议一致：默认不宣称确定性排版或无字盲审，本地路线不能用带字生成稿冒充无字底图。
- 正文、日期、出处和宜忌逐字准确。
- 正文是第一信息层级，图像不能抢走全部注意力；不以全句最大最重冒充层级设计，日期、出处和宜忌不抢成第二标题块。
- 换行符合语义，不拆词或制造错误强调。
- 无重叠、裁切、缺字和低对比。
- 正文与全部辅助文字由设计留白承托，与图像主体、可辨细节和明显纹理保持视觉间隔；直接压在图像上、像摄影作品加字幕，即使清楚可读也不得通过。留白须参与整体构图，不以固定白底块或空白比例代替判断。
- 最终PNG尺寸与记录一致。
- 按排版参考检查阅读节奏、具体图文关系、层级与呼吸、实际文字声音及字形适配；清楚但像另贴一块通用文字的方案不能只凭可读放行。字体选择开放、实际加载且不缺字，不能凭类别名称或静默回退后的理由放行。简洁、重复字体或较大字号本身不是问题；判断依据是本句与成品的具体关系，不是装饰多少或每天新奇。

schema 1.4 不再要求排版总分。正文、出处、宜、忌各有原尺寸的实际可读结果及简短证据；任何一组失败即返回排版。日期／星期与记录一致，成品经完整PNG解码，指纹对应本次登记版本。

## 6. 隔离输入的语义冷审

### 输入

默认按 [integrated-production.md](integrated-production.md) 使用隔离上下文的有字成品审核：最终卡片、360px、准确文案、必要语境与固定问题，不给预案／提示词／理念。承认文字可见，不称无字盲审，分开观察事实与文案暗示。本地路线才执行 [semantic-art-direction.md](semantic-art-direction.md) 的两阶段无字→揭句协议。自审不能标独立；实际身份、输入和原始输出均登记。

### 固定问题

1. 第一眼看到的主导关系是什么。
2. 可见的是动作、共存、边界、节奏还是其他状态；仅有变化线索时追问方向和原因。
3. 最强误读是什么。
4. 揭示句子后，图文共享的关键关系是什么。
5. 是否缺少关键动作、关键状态或因果链。
6. 是否必须阅读设计说明才能成立。
7. 独立于题意吻合，画面通过状态／关系转译，还是用人物或情节直接演示、仅用装饰贴标签？填写 `expression_review`，不能沿用设计者结论。
8. 看有字成品后，文字实际是什么声音、怎样停顿，主次和图文整体关系如何？按排版参考的四项写具体词组、区域或字形依据，不先提供设计者选型理由。新版1.5第二阶段输入自动带 `typography_review` 合同，输出必须有 `typography_design_review` 的四项观察与 pass/revise；实质问题返回排版，纯偏好不同不触发无休止返工。脚本核对合同和结论，不自动核定审美真伪。

区分实际可见、揭句后自然关联和仅由设计者设想三层。审查者先依据原始语境形成句意，说明支持与归属限制，不把卡片的积极语气当作作者立场。对核心因果缺失不能放水，对无需直画的余味也不要强求逐字解码。独立输出封存后，创作者再从文本依据核对核心解释、重点、概念和可见关系；句意错则退回语义锚点，即使图完全符合提示词也不能通过。不能重写观察让它匹配预案。

### 放行

只有同时满足以下条件才可通过：

- 实际使用未继承创作历史的独立上下文，输入合同与对应路线一致。
- `missing_link=none`
- `explanation_required=false`
- `decision=pass`
- schema 1.5 对应路线原始输出的 `expression_review.decision=pass`，且分类不违反锁定边界；自然相关、文字清楚不能抵消表达失败。
- 原始输出的 `typography_design_review.decision=pass` 且四项观察完整；任何 revise 不被总体 pass 抵消。默认还需六组 `copy_check.matches=true`、无额外字，以及各组 full_resolution 通过。历史按封存合同回验，不追认新检查。

且当前图片／文字指纹与被审版本一致，对应路线原始输出可回读。全链路重新确认原句→编辑重点→概念→成图实际关系，没有丢失关键动作或状态；不能只检查提示词执行度。结构字段不能保证审美／语义判断永远正确。

可替换无关文字测试只在怀疑画面过泛时使用，结果写入 `optional_genericity_test`；不再是每日硬门槛。

## 7. 对外设计理念

检查四部分是否自然完整：

- 选择的句子：逐字准确，含作者和作品。
- 这句话在说什么：只解释上下文支持的核心含义，实际说话者、对象和必要限制准确，不把本卡延伸说成作者原意。
- 希望配图表达什么：说明承接的原句关系和观者应先感到的状态；确有生活联想须明确是本卡联想，不能代替准确句意。
- 画面为什么这样设计：所采用的题材、载体、关系、构图、色彩和留白承担明确作用，取舍有依据；不要求每张画面都表现运动或事件因果。

理念必须来自生成前锚点与胜出概念，不承担挽救失败图片的职责。参考长度350–650字；结构验证允许200–1000字。文件与 `design_concept.full_text` 必须逐字一致。

理念不得包含提示词、失败版本、冷审过程、无关文字测试、尺寸检查、发送回执或生成后偶然细节。

## 8. 失败回退

| 失败层 | 识别信号 | 动作 |
|---|---|---|
| 内容失败 | 原文、出处、译本、查重或选句失效 | 返回内容选择 |
| 语义失败 | 编辑重点改变原意，视觉命题承接错误 | `return_to_semantic_anchor` |
| 概念失败 | 太直接的场景演示，或主导关系难以感知、解释依赖过强 | `return_to_concepts` |
| 执行失败 | 概念成立，但生成漏掉关键动作或状态 | `regenerate_same_concept` |
| 排版失败 | 字小、拥挤、低对比、层级被图像压过，或图文关系松散、节奏与语气不符 | 默认一次针对性图像编辑／重生并重审全卡；本地才改排版源，不重跑无关选句 |

## 9. 最终放行

完成前六项和实际看图后可把 `qa.final_status` 设为待验证的 passed；只有最终脚本也通过才能交付，不能把自行设置的值当成成功回执：

1. 历史查重、内容诚信和选题广度通过。
2. 白话锚点和概念竞争完整。
3. 执行闸门通过。
4. 对应生产路线证据成立，原尺寸文字准确、可读。
5. 语义冷审的自然关联、表达适配与适用的排版设计合同均通过。
6. 四段式对外理念与发送文件一致。
7. 生产模式 `validate_record.py --stage final` 返回 `VALIDATION PASSED`，检查当前内容、历史新鲜度和图片证据；归档模式只回验当时事实，不能替代本次生产放行。
8. 人工查看最终图通过。

结构验证通过不等于作品通过。不得发送任何未通过语义冷审的图片。
