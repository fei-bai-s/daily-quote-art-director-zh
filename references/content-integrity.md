## 1. 内容类型

先把候选文字归入且只归入一种类型：

设计记录使用固定机器值，禁止填写中文别名：

| 内容类型 | `content.text_type` |
|---|---|
| 原文摘句 | `exact_quote` |
| 版本化译文 | `translated_quote` |
| 作者谈作品 | `author_about_work` |
| 自写摘要或取意 | `editorial_summary` |

### 原文摘句

作品中可逐字定位的短句或短段。正文保持原文，不润色、不补标点、不做“更顺”的改写。

标注：

```text
作者《作品名》
```

必要时补篇章、卷次或章节。

### 版本化译文

外国作品的中文译文。中文措辞依赖译者和版本，不存在脱离译本的唯一“原句”。

标注：

```text
作者《作品名》｜译者：某某
```

无法确认译本时，换候选；不要把网络流行译法当作定本。

### 作者谈作品

作者在访谈、自序、演讲或书信中解释某部作品，但文字不一定出现在作品正文。

标注：

```text
作者｜谈《作品名》
```

不得简写成 `作者《作品名》`，以免误导为正文摘句。

### 自写摘要或取意

由执行者概括作品思想，或用现代语言重述原文。

可用标签：

```text
今日摘要
取意自 作者《作品名》
```

用户要求原句或明确反对改编时，禁止使用这一类型。

## 2. 来源优先级

从高到低：

1. 可访问的原作、作者手稿、正式电子版或可靠影印本。
2. 作者、出版社、版权方、图书馆、文学馆、大学研究中心。
3. 中国作家网、人民文学、权威报刊和正式文化机构。
4. 有清晰版本信息的书评、课程或学术文章。
5. 普通媒体和个人文章，只能辅助定位。
6. 语录站、社交媒体图片、短视频文案，不可作为唯一证据。

若高优先级来源与流行说法冲突，以可核文本为准。

## 3. 核验流程

1. 搜索完整句和关键短语，不只搜作者名。
2. 打开原页面，确认页面确实包含该句。
3. 判断页面是在引用原文、转述观点，还是自行评论。
4. 核对作者、作品名、篇章和标点。
5. 记录 URL、页面标题和核验说明。
6. 再搜一个独立可靠来源处理误引风险；原作本身可单源定案。
7. 若仍不确定，换一句，不以“网上都这么说”放行。

每条有效候选至少保存 `source_locator` 和 `source_note`，不是只写 `verified`。胜出项的 `chapter_or_context` 必须含能支持句意的原文上下文或精确篇章定位，而不只是执行者的积极化转述；同时核对讲话者、反讽、转折、限制及作品整体语气。可选择其中有力量的侧面，但不能把编辑侧重冒充原作唯一态度。

### 句意依据与归属合同

逐字核验与句意核验分别成立：找到原句不能证明当前解释就是原意。先读相关上下文，直到能辨明说话者、讨论对象、论证／情节作用、转折及限制；诗歌可读全篇，访谈至少读对应问题与完整回答。不要求读完整本书，但关键语境不可缺。

在唯一语义记录 `plain_brief.meaning_basis` 保存：

- `source_locator`：实际读过的来源 URL＋段落／章节，或本地源文件＋页码；可复用既有核验来源。
- `supporting_text`：逐字摘录足以约束句意的相关原文，包含本句并保留关键上下文；同一摘录存入 `content.chapter_or_context` 供独立审查，不能用模型概述替代。只存必要片段，不复制整篇作品。
- `attribution_scope`：本人访谈、叙述者、人物台词或抒情声音等实际归属及讨论对象。文学文本的说话者不能直接升级为作者人生主张。
- `support_note`：简述核心解释如何由这些原文支持，特别是关键词、关系与适用范围，不另写一篇鉴赏。
- `limits`：哪些含义未获支持或仍不确定；“作者明确表达”与“结合文本可作此理解”分开，不推测不可证的作者心理。

`core_meaning` 是据此作出的忠实概括，不必逐字复述，但不得添加原文没有的劝告、因果、保证或价值立场。`selected_emphasis` 只突出已有侧面。执行者的生活应用或联想另存 `plain_brief.editorial_extension`（没有则空字符串），不回填核心解释或语义不变量。联想即使合理，也不能因为“不矛盾”就称为作者原意。

无法支持关键解释时补读原文；仍有歧义则限定表述，不能为了日签正向性强行定论。开放选句可换候选；指定文字则说明缺口。新初始化记录启用 `run.meaning_grounding_required=true`，pre/final 检查依据字段、摘录与上下文的绑定及生成锁；脚本不证明摘录真实或解读正确，这仍须阅读判断。历史未启用合同不补造证据或改写已交付记录。

## 4. 外国文学与译本

- 优先选择已知译者和出版社版本。
- `translated_quote` 的 `translator` 与 `edition` 都必须非空，后者能定位具体出版／电子版本；翻译访谈也适用，并在来源字段说明访谈载体。不要为兼容“作者谈作品”而省略译本信息。
- 原文语言可核但中文译者不明时，不能自行翻译后标为作品原句。
- 只有用户明确授权自译时才可展示原文并标明“本卡译文”，按自写内容处理，不标为版本化译文。本项目要求原句时不走此兜底；用户指定的句子无法核实时先说明缺口，不擅自换掉。
- 同一句出现多个常见译法时，选定一个具体版本，不拼接多个译本。
- 避免使用长期存在误传的“世界名著名言”，除非已定位原文。

## 5. 选择标准

候选文字至少满足：

- 有独立意义，但不脱离上下文到反转原意。
- 长度适合一张卡；过长会损害阅读层级。
- 存在可视觉化的关系、张力、节奏或转折。
- 不只是空泛口号。
- 能承载安慰、好奇、热爱、幽默、清醒、耐心、勇气或力量中的一种。
- 与近期内容不过度同质。

默认不把“积极”理解为强迫振作。允许平静、哀而不伤、承认局限和温柔的现实感。

## 6. 标注规则

正文下方的来源标签必须让普通读者一眼看懂：

| 情况 | 正确写法 |
|---|---|
| 原文 | 作者《作品》 |
| 作品内具体篇章 | 作者《作品·篇章》 |
| 作者谈作品 | 作者｜谈《作品》 |
| 自写摘要 | 今日摘要；另写“取意自……” |
| 译文 | 作者《作品》｜译者：某某 |

不要用“出处”掩盖类型差异。

## 7. 高频错误

- 把广泛流传等同于真实出处。
- 只核作者，不核句子是否真的在作品中。
- 把作者访谈中的话放进小说正文。
- 为了版面擅自删改原句。
- 省略译者导致译文无法复核。
- 看到一句适合画面就忽略上下文。
- 每天都选择“坚持、向上、熬过去”，造成主题惯性。

## 8. 作者背景与使用适宜性

目的：避免把有可靠严重问题记录的人，不加辨别地放进安慰、鼓励类署名卡片；不是寻找完美作者、按网络热度站队或制作永久黑名单。作品价值、作者言行和本次署名传播是否合适分开判断。

### 何时、查多深

只对暂定胜出作者必查，候选阶段已有明确风险则提前处理。先核姓名、笔名、年代和作品，防同名误伤；看可靠生平或文学评价，再做一次中性背景检索和一次争议／公开言论检索。近现代、在世作者兼顾近期报道，外文作者必要时查原文语言。常规核查找到可读背景来源、完成风险检索且无可信严重线索即可停止；出现线索才追查事件，不把日签变成人物传记工程。匿名、集体或归属存疑作品注明归属限制，不编造个人背景，也不因缺乏资料而判“清白”。

### 证据与边界

- 基础评价参考文学机构、可靠传记、研究或正式媒体，不用奖项证明品行，也不用负面搜索数量证明问题。
- 争议回到原始访谈、文章、公开记录或可靠报道，核实际说话者、日期、完整语境；区分本人立场、虚构人物台词、反讽、引用和转述。必要时交叉核对独立报道，不把同源转载算多份证据。
- 分开记录已证实事实、尚有争议的指控和编辑判断；查后续澄清、更正、回应或撤回。只有截屏、剪辑、匿名爆料或搜索摘要时，不能给人定性；打不开关键正文就保留缺口。
- 关注明确鼓吹暴力、贬损特定群体或弱者的严重言论，以及有可靠记录的严重侵害、造假等。说明具体内容及其与本卡使用的冲突，不写“逆天”“塌房”这类标签。
- 普通审美分歧、政治观点不同、时代局限或合法身份本身不自动淘汰；古人也要看语境，不用一句传闻概括一生。查无可信线索只写“本次检索未发现影响本卡使用的可靠严重问题”，不承诺作者没有问题。

### 决策与留痕

`content_selection.author_review` 保存：`candidate_id`、`author`、`checked_at`（含时区）、`identity_note`、`queries`（实际检索词）、`sources`（每项 `url/title/note`，注明支持什么）、`findings`（事实状态、语境及来源）、`decision`、`rationale`、`limitations`。日常无异常时简短记录，不写长篇风评报告；读过的原文核验来源可复用作背景证据，但不能替代风险检索。

- `pass`：核查完成；没有可靠严重问题，或普通争议经语境判断不影响本卡。说明依据与检索边界。
- `replace`：严重问题可靠成立，本次正向署名传播不合适；开放选句默认换候选，保存原因后重走该候选核验与查重，不必重做无关探索。
- `needs_review`：有可信且可能影响使用的严重线索，但事实未明或来源不可读。开放选句可暂缓此候选、换另一位；暂缓不是认定指控成立。用户指定作者／原句时简要给出可靠出处和不确定性，请用户决定，不擅自换句，也不把指定视为已知情接受风险。
- `pending`：尚未完成，不能进入生成。换候选或出现新的可信信息时重审；同一轮未换作者、仅调排版不重复调查。不同日期可复用已核生平并引用旧记录，但仍刷新风险检索，不能沿用永久“安全”结论。

新记录通过模板中的 `run.author_review_required=true` 启用结构检查；旧记录不追认。脚本只核记录完整、对象一致和 `pass`，不能证明调查质量或作者声誉。对外日签默认不附背景报告、不把核查结论写成对作者人格的背书；只有影响用户选择时才单独说明。此更新不自动修改定时配置或重审历史成品。
