# 前向压测场景

新创作默认 `integrated_image_text`。下文涉及本地字体、小样、排版源、无字盲审或 prepare-layout 的场景只测试明确 `local_typesetting`／历史路线，不得让测试案例反向恢复旧默认。其他选句、语义和表达场景对两路线均适用；带字路线按独立可见事实而非伪称无字盲读判断。

## 图文一体 B 方式回归（非每日必做清单）

- 同一已核文案与画面概念，只加简短专业设计原则，不指定宋体、左对齐、两行、字重、字色、坐标或上下模板；题材不是固定石头／布料／摄影。前置内容、作者、查重和概念竞争仍执行。
- 六组完整准确文案必须在锁定提示词及实际请求中出现；修改辅助文案、星期、生产模式使生成锁失效。no text 与准确文案并存必须拒绝。
- 原始生成PNG原字节复制为成品；本地覆字、裁切、替换原图、伪造排版源或 `final_text_rendered_deterministically=true` 必须拒绝。允许明确本地路线继续走旧正向链。
- 错误字词／标点、额外文案、表达方式或四项排版 revise 同样阻断。
- 独立输入含准确文案与原始语境，不含预案／提示词／理念；诚实标为有字上下文隔离审查，不包含 image_only_reviewed_at。原始审核与实际图像指纹绑定，图片变化或改写审核文件须失效。
- 默认不做本地双小样或两路线同时生产，不每日重复 A/B；同概念初版加一次修正仍失败则停止说明，请用户决定继续或换路线，不偷偷覆字放行。
- 机械回归需要一条完整可通过的合成链和上述拒绝例；合成图片／模拟观察只能验证合同，不称新成品视觉质量已通过。真实新图验证在下一次日签进行，不为更新流程擅自新增外发。

## 目的

用陌生任务验证 skill 是否真正泛化，而不是只会复刻已完成案例。

## 句意依据回归（非每日新增竞赛）

- 格非访谈的原问题讨论文化／语言特殊性，完整回答用城乡经验说明差异在比较中显现：核心解释应保留这个对象与关系。“不必防守、不必评判”是日签联想，“谁也不会被抹掉”是视觉选择，均不能归入作者原意；两种不同形态经对照更显特点的概念仍可成立，不机械否定所有交叠图。
- 小说人物在特定情节中作出激烈主张，叙述及后文对此形成反讽：按人物归属和上下文解释，不改成作者励志格言；找不到必要语境时不能进入概念设计。
- 同一句可支持多种有限读法：承认边界，不编造作者唯一心理；仍可从有依据的侧面竞争视觉概念，不强制制造三种句意。
- 画面准确表达“接触必然使双方更好”，而原文仅说比较使差异显现：判语义失败，退回锚点或概念，不能因提示词执行成功或图好看放行。
- 新合同缺上下文、摘录不是原文上下文中的逐字片段、没有本句、归属或解释边界缺失时，pre/final 结构检查拒绝；真实完整依据可通过，改依据或关闭合同使原锁失效。旧记录不被追认为已做此核验。

这些案例校准证据与创作的边界；脚本只检结构与绑定，不能声称自动识别原文真伪、反讽或解读正确，也不为规则更新新增图像或外发。

## 场景 A：外国小说与译本歧义

用户：

```text
用《老人与海》做今天的日签，选一句最有力量的。
```

必须做到：

- 找到具体译者与版本；没有授权时不得自行翻译兜底。
- 不混合网络上的多个中文译法。
- 风格从句子结构得出，不自动使用海洋摄影。
- 不把原句名词与情节逐项复述成插图；不因出现海等名词就机械判失败；人物主体需用户明确例外，选书或选句不是例外授权。

失败信号：

- 直接使用流行中文名句却没有译者。
- 直接复刻故事情节，未建立与选句有关的独立视觉关系。

## 场景 B：用户喜欢上一张风格

用户：

```text
上一张纸艺很好看，再做一张，文字随便。
```

必须做到：

- 把喜欢纸艺当作偏好证据。
- 先选文字并判断纸艺是否适合。
- 若改用其他媒介，解释内容证据。
- 若继续纸艺，写出为什么不是惯性复用。

## 场景 C：疑似伪名言

用户：

```text
用“世界上只有一种英雄主义……”做一张。
```

必须做到：

- 核查作者、作品和原文。
- 无法确认用户指定句子时说明风险并请求选择；开放搜索可换候选。未经授权不得改为不署名摘要或自译。
- 不因句子流行而直接归给罗曼·罗兰。

## 场景 D：古诗原句与反直译

用户：

```text
用“行到水穷处，坐看云起时”，不要古风。
```

必须做到：

- 核实原诗。
- 不把诗中山水和坐看情节逐项画出；允许具象但非直译的另一场景。
- 从原文语境确定编辑重点，再竞争画面；“尽头 / 另一种发生”只是可能重点，不是预设唯一答案。
- 风格可以现代，但来源与原文保持准确。

## 场景 E：局部重叠修订

用户：

```text
出处和装饰重叠了，只去掉装饰，其他不变。
```

必须做到：

- 修改可编辑源或局部修复底图。
- 不重新生成整张图。
- 输出新版本并回读全图。

## 场景 F：内容方向变化

用户：

```text
这次不要坚持和逆境，选一句有幽默感、让人松一点的。
```

必须做到：

- 主题惯性检查有效。
- 选择真实、可核的幽默文字。
- 宜忌不过度励志。
- 视觉节奏允许轻松和反差，不沿用沉重材料。

## 场景 G：开放候选池

用户：

```text
今天随便选一句，但不要总从那些常见作家里选。
```

必须做到：

- 候选池是本轮临时生成，不读取固定名句库作为封闭范围。
- 搜索可以跨时代、文化和体裁，但不机械凑配额。
- 先重建全系列历史索引并形成当日编辑任务。
- 至少使用 4 条探索路径检查 12 条初步线索，保留 5 条作者不同、来源与语义有差异的有效候选。
- 写清为什么停止扩展，以及胜出项比次优项更适合今天的原因。

失败信号：

- 候选都是同一主题的近义句。
- 只在熟悉作者名单中轮换。
- 为了形式上的多样性牺牲内容质量。

## 场景 J：跨日期完全重复

历史中已经交付：

```text
不怕他真理无穷，进一寸有一寸的欢喜。
```

新一天开放选句再次把它列为胜出项。

必须做到：

- 全历史检查找到既有日期和记录路径。
- `history_dedup.decision=failed`。
- 生成前锁定失败，不得进入语义卡和图像生成。

## 场景 K：标点或少数字词变化

历史中已有泰戈尔句子，新候选只改标点、空白、繁简或增删句末虚词。

必须做到：

- 标准化完全匹配时按重复处理。
- 高相似但不完全相同时进入近似匹配。
- 不把网络流行改写当成新的选题。

## 场景 L：作者不同但语义同质

五条候选分别来自不同作者，却都表达“坚持下去、熬过困难”。

必须做到：

- 结构化语义签名暴露同质问题。
- 不因作者不同就通过选题广度闸门。
- 继续向幽默、好奇、关系、日常发现或其他真实不同的力量来源扩展。

## 场景 M：用户明确要求复用

用户：

```text
还是用昨天这句，再换一个设计。
```

必须做到：

- 使用 `user_supplied` 或 `revision`，不伪装成开放选句。
- 记录 `reuse_authorized=true` 和用户指令。
- 历史检查得到 `passed_with_user_override` 后才能继续。
- 不把这次复用计为未来开放选句可以重复的先例。

## 场景 H：画面可解释但主导感知冲突

生成前意图：

```text
压力在达到峰值后耗散，不能占满整个生命表面。
```

成图第一眼却像正在爆炸或持续燃烧。

必须做到：

- 使用隔离输入的语义冷审，不向审查步骤提供提示词、设计说明或材料象征。
- 把“爆炸正在发生”记为主导误读。
- 即使局部痕迹能被解释成耗散，也把 `missing_link` 记为 `relationship_conflict`。
- `decision` 使用 `regenerate_same_concept` 或 `return_to_concepts`，不得放行和发送。

失败信号：

- 用更长的设计理念把冲突说圆。
- 因为艺术指导评分够高而抵消感知闸门。

## 场景 I：每日发送的设计理念

用户：

```text
设计理念应该是从选定诗句到调用 AI 出图之间的完整内容。
```

必须做到：

- 使用“选择的句子—这句话在说什么—希望配图表达什么—画面为什么这样设计”四部分。
- 直接继承白话语义锚点与胜出概念，不另造一套解释。
- 参考长度350–650个中文字符，结构验证允许200–1000字符，并与实际发送文件逐字一致。
- 不写提示词、失败版本、冷审过程、尺寸检查和生成后偶然细节。

失败信号：

- 只描述画面上出现了哪些颜色和材质。
- 只写抽象主题，没有说明为什么这样画、具体怎样画。
- 设计理念中写出的关键关系没有通过盲读检验。

## 场景 N：梁鸿关系缺失回归

原句核心：

```text
微小力量逐渐积累，并开始使现实发生变化。
```

锁定概念：分散针脚聚集后，共同牵动沉重毡面。

成图只能看见针脚从疏到密，看不见针脚使毡面移动、隆起或变形。

必须做到：

- 执行闸门或语义冷审识别“因果链缺失”。
- `missing_link=causal_link`。
- 不因聚集节奏、暖色或纤维材质符合提示词而放行。
- 概念仍可被清楚执行时重生同一概念；概念本身难以显现因果时返回概念竞争。

## 场景 O：后半段完整概念竞争

用户只指定一句核验后的文字，没有指定画面。

必须做到：

- 核心含义只保留一份；编辑重点可比较，但不制造三种互斥解释。
- 形成至少三套完整视觉概念，而不是分别生成三种关系、三种媒介和三种构图。
- 至少两套概念使用不同表达机制。
- 三套概念不能只是同一抽象材料隐喻换材质。
- 胜出理由按语义准确、关系可感知、情绪适配、文字空间、近期差异的顺序判断。

## 场景 P：非变化型句子

句子表达两种感受可以同时存在，彼此不取消。

必须做到：

- 允许使用共存型核心视觉命题。
- 不强行套用“A通过动作使B改变”。
- 第一眼关系应是“同时存在且边界清楚”，不是必须出现移动或转化。

## 场景 Q：定向与局部修改快路径

用户分别提出：

```text
用这句话，画面明确做成低机位静物摄影。
```

```text
只把正文放大，其他不变。
```

必须做到：

- 前者允许 `concept_competition.mode=directed`，记录用户指令，不为凑数生成三种媒介。
- 后者继承未变内容与底图，登记新排版指纹并重跑可读性检查；无字审查视图不变可继承第一阶段观察，不重跑选句、概念竞争或底图生成。

## 场景 R：语义锚点不能预先选画面

原句允许突出“未来未知，当下亲近仍有价值”。检查锚点是否提前写成“两个物体融合出第三色再分开”。后者只能是某套概念的创作选择；先还原纯语义约束，再比较完整概念，不能让三套材质方案围绕它凑数。

## 场景 S：自然关联与过度解码

无字图只见两条平缓色带局部交叠。独立审查可以在揭句后认为它与“短暂相亲”自然相关，但不能在第一眼记录中虚构靠近、相互改变和之后离开的时间线。也不能因无法唯一读出人物或未来，就要求画面改成直译插图。

## 场景 T：版本变化必须使旧结果失效

在临时副本测试：查重后换句；索引后新增已交付记录；最终图换成同尺寸白图；PNG截成24字节；重新登记底图；只改字号；出现未来日期的同作者记录。分别检查输入绑定、新鲜度、完整解码、下游失效、局部修订继承和历史冷却。必须同时有真实可通过的正向链，不能只测拒绝所有输入。

## 场景 V：关联自然但表达方式不合适

使用2026-09-05萧红人物卡作为已知用户否决案例，而不是未知盲测。原句为“要做什么，就做什么。要怎么样，就怎么样。都是自由的。”图中三人分别阅读、伸展、静坐。预期：可承认自然相关，但默认下 admission=reject；实际成图 expression_review=fail，不能凭 natural 放行。真人照片、玩偶或拟人动物演相同动作也不能自动过关。

## 场景 W：无人物不等于隐喻成立

给出一片蓝色渐变，仅说明“蓝色代表自由”；以及疏密针脚却没有牵动毡面的图。前者是装饰贴标签，后者缺失计划所依赖的关系；都不能因没有人物而通过。分别返回概念或执行层，不把所有失败都归为风格错误。

## 场景 X：具象与关系隐喻可以兼容

已知概念正向校准：一句话允许“保持整体的接纳，同时拒绝局部”。一件连续器物上只有局部表面被粗糙处理，整体形体仍清楚完整；用静物摄影或绘画均可。预期：不因具象或摄影而淘汰，比较实际完整／局部区别是否可见；不宣称仅有概念文字就已经通过真实成图验收。此例不是每天复用的器物模板，单有“裂缝代表希望”也不够。

## 场景 Y：明确例外与不明确的换风格

分别测试“这次明确用人物主体做休息场景演示”和“换一种风格，别总用材料”。前者记录实际用户原话与对应两个例外布尔值，再检查内容、可感关系和阅读性；后者不能自动开启任一例外。明确允许人物而未允许直接演示时，只放宽人物边界，不能一并放宽机制。

## 校准使用边界

作者背景增补校准（不要求每天执行这些测试）：

- 搜索只有匿名截屏，完整作品显示其实是反派台词：不归为作者本人言论；查清后可 pass，不能因热度 replace。
- 可靠原始访谈确有严重贬损弱者言论，完整语境及后续回应未改变判断：开放选句 replace；作者获奖不抵消使用风险。
- 可信报道提出严重指控但证据及后续结论未明：needs_review，换候选是暂缓使用，不是认定有罪；指定作者时先说明并询问。
- 只有普通文学／政治观点分歧：不自动淘汰，结合具体内容说明使用适宜性。
- 新记录缺作者核查、核查对象与胜出项不同、状态仍 pending 或缺来源：结构闸门拒绝；旧记录不被追认，局部字号修改不重造调查。
- 没找到可靠严重线索：限定为本次检索结论，不写作者无任何问题、不对外追加人格背书。

上述案例校准两条独立判断：关联成立、表达适配。已知反例／概念例只证明规则能否正确区分，不能当作用户实测或新图成功。现有已获用户认可的成图可做正向参照，必须回读当时实际图像、句子与具体可见关系，不以“用户说好看”或某种媒介作为通用通过理由。更新时另用陌生文字与非固定题材做前向判断；不要把所有边界案例加入每日生产的必做清单。

## 通过标准

### 执行效率回归

- prepare-layout 后、register-layout 前启动无字冷审：第一阶段输入仅有匿名无字图与固定边界；最终排版未登记时 cold-stage1 不得生成揭句材料。
- 排版与无字审查并行后，完整登记及 final 仍通过；更换无字裁切、揭句后才完成排版、使用未来时间或同一创作上下文审核仍须拒绝。
- generation-complete --select 不替代执行看图；execution --prepare-layout 遇到失败结论应停止，不能生成可用排版状态。
- 秒内连续写理念与 final 校验不应因时间被截断误拒绝；真正的未来时间和顺序反转仍拒绝。
- 不因追求用时目标删减有效候选、作者风险检索或独立审查；只改字号不重新开放选句。真实提速结论须来自新的完整生产，不以本地测试运行速度代替。

### 图文排版案例

- 整幅摄影上直接叠字，即使浅色石面上的正文和深色实景上的页脚都读得清，也应因缺少承托文字的设计留白而 revise；文字位于参与构图的留白、与图像主体和纹理有视觉间隔，且图文有真实平衡或呼应的方案可通过。不要求固定白底或上文下图。
- 给一句有对照结构的短句和一句舒缓的长句，分别确定实际声音与自然停顿，再做同概念双布局小样。两案各有阅读组织或图文构成假设，不用同一标题块换宋／黑体或微移第二行充数；仅字体变化确实改变声音或体量关系时，须指出实际差异。校准文字不是正式选句，不导入系列历史。
- 两版都清楚，一版图像与文字各自成块且无整体关系，另一版有明确对齐或体量呼应：必须比较具体关系，不能两版都因“可读”直接通过。
- 温和交流的原句被排成全大、全粗的宣言，正文可读但声音偏移，或日期／出处／宜忌抢成另一个标题块：独立审查写具体依据并 revise；脚本必须阻止排版 revise 被总体 pass 抵消。大粗字本身不禁用，适合明快判断的正向例仍可通过。
- 简洁左对齐版与错位花体版竞争：允许前者胜出；后者拆词、误强调或降低阅读性时淘汰，不能把装饰当设计感。
- 连续使用同一字体、居中或上文下图，若实际语气、阅读与体量关系成立，可以通过；历史相似只触发重判，不自动淘汰。两案共用结构均不适配时先修共同问题，不强选较不差者。
- 候选字体缺字或不可用：用实际正文查看可用资源并扩展，不静默回退、不封闭到宋／黑名单，也不为日常出卡默认安装字体。局部“这张字小”不推导成以后全大粗字，“这张很好”不固化布局。
- 小样文字空间充足，实际底图侵占文字区：不能不断缩小正文迁就图片；调整落位或修底图，并重新审核受影响版本。
- 新1.5第二阶段输入自动带四项排版合同，不泄露预案；缺 `typography_design_review`、缺任一观察、结论无效、合同被改均须拒绝。完整 pass 能正常放行；旧1.4／1.5无此合同的原始快照仍按旧标准回验，不冒充新审美通过。
- “只放大字号”仍走局部修订，不强制双案、不重跑选句。未真实渲染的小样不得记为完成；规则推演通过不等于新成品已经获得用户认可。

按场景涉及的阶段验收，不要求局部修改重造全套历史。完整创作应产生：

1. 可核的系列历史索引和选题历史检查。
2. 正确的内容类型。
3. 可核来源。
4. 从零创作时真实、多路径、非同质的候选记录。
5. 生成前语义与艺术方向记录。
6. 不依赖字面插图的提示词。
7. 明确生产路线的图文设计与登记证据；默认自主文字生成，本地才确定性排版。
8. 隔离输入的语义冷审记录。
9. 与白话锚点和胜出概念一致的四段式设计理念。
10. 完整 QA 记录。

前向测试应使用新工作目录，避免读取已有案例产物作为答案。
