## 1. 图文共同设计：默认图文一体

文字是构图的一部分。默认 `integrated_image_text` 在一次生成中完成画面与文字；选句、原文及作者核验、语义锚定、完整概念竞争不变。默认路线不先制作本地双小样、不搜本地字体、不传具体字号／字体／对齐／行数／坐标。不是让模型重新决定画面含义，而是让它在已明确的画面概念内设计图文构成。

完整概念的 `implementation` 交代画面体量、疏密与文字共存的可能性，不预先锁死文字块的位置、轴线或阅读顺序。留白来自内容，不固定上文下图或空白比例；也不为了不同而禁止简洁分区。

**文字由留白托住，不直接压在图像上。**正文与全部辅助文字都落在专门设计的留白中，与图像主体、可辨细节和明显纹理保持视觉间隔，让文字从图像中退出来。仅在照片里找一块颜色较浅或较平、字能读清的区域，不算完成这项设计；留白本身要参与整张卡的疏密、平衡和图底关系，而不是“摄影作品加字幕”。留白的位置、形态和底色自主设计，不固定成白底矩形或上文下图。两条生产路线均遵守。

提示词保留准确文案（正文、作者与完整作品／译者、日期、星期、宜、忌），要求全部出现且不改字、不添加额外文案。随后使用以下简短专业指引，不叠加具体排版参数：

> 以编辑设计与字体排印的专业方法，把文字与图像作为同一件作品设计。根据这张卡的需要，运用格式塔的接近、相似和图底关系，以及视觉重量、光学对齐和中文排印的阅读节奏；不必使用全部原则，也不要把术语印在图中。所有文字由专门设计的留白托住，与图像主体、可辨细节和明显纹理保持视觉间隔，不直接压在图像上；不是在照片里找一块字能看清的背景加字幕。留白的位置、形态和底色由你设计，并参与整体构图。让句子自然连续读完，不因换行、字距或强调而割裂词组；辅助信息清楚但不争夺注意力；文字的声音、疏密与画面的体量和气氛相互支持。字体、字号、位置、换行、字重、字色和具体构成全部由你自主决定。

这是 B 方式的原则，不是 B 成图的样式模板。无需讲完设计理论，也不要求每张使用全部原则；不复制它的宋体、左对齐、两行、摄影或堆叠页脚。不得在专业指引后追加一整套具体字号、落位和断行方案，架空自主设计。看图后记录实际效果，不臆造真实字体名称。登记、独立审核与准确性合同见 [integrated-production.md](integrated-production.md)。

### 明确本地路线才执行下列小样与资源选择

胜出后，先在现有 `pre_generation.typography_direction` 用两三句写明**本句的文字声音**：读起来是交谈、沉思、明快判断，还是其他有原文依据的语气；自然语义分组和停顿在哪里；本次适合突出某一处，还是保持全句均衡。依据唯一 `plain_brief`，不另造句意。不要先决定“文学用宋体”“正向就放大加粗”再补理由；这份声音说明用于设计，不预先交给独立审查者。

胜出概念锁定前，用本地真实字体、准确正文及辅助文案做两种低成本布局小样：图像用符合预定位置和体量的简单占位轮廓即可，不调用 imagegen。每案先用一句话提出不同且值得认真比较的**排版假设**：怎样组织阅读或图文构成，能更好地承接本句的声音与关系。再据此渲染，不用明显差案陪跑。

两案至少在文字块结构、对齐关系、图文比例或阅读节奏之一有实质差异。只换宋／黑体、字色或微移第二行通常不足；若字体变化确实改变了本句的阅读声音或整张卡的体量关系，必须指明实际差异，不能只凭字体分类宣称两案不同。不强制横排对竖排，也不要求夸张造型。一次并排查看原尺寸，比较声音、节奏、图文整体性和可读性，简记胜出理由与另一案的具体代价。若两案共用的结构都不合适，先修共同问题，不默认选较不差的一案。明确限定字号／落位的局部修改不做双案。

小样保存在本轮工作目录；在现有 `pre_generation.typography_direction` 中记录两案路径、取舍及胜出布局要点，在 `negative_space_plan` 中登记对应文字区。无需增加 schema 或另写设计报告。脚本不验证这些自由文本的设计质量，必须真实看小样，不能写“已比较”代替比较。

字体选择必须查看实际字形，不只根据字体名称归类。结合本句检查笔画粗细、字面大小、中宫疏密、标点和整体语气；现有字体不适配时再找其他可用字体，不强制每天安装或更换字体。不把使用的字体数、装饰数当作设计完成度。

- 使用 `imagegen` 生成或编辑视觉底图。
- 底图默认不含正文、日期、出处和宜忌。
- 在提示词中为后续排版明确预留负空间。
- 生成后保存到项目 `work/`，不要把项目依赖资产只留在默认生成目录。
- 先检查底图是否保留计划的图文关系，再微调最终换行和字号。若图片挤占文字区，先调整可行落位；无法保持计划与可读性时修正底图，不持续缩字迁就图像。底图或裁切改变时按既有规则重做受影响审核。

上述无字底图、双小样、本地字体和确定性叠字只适用于明确选定的 `local_typesetting`，不是默认路线必做步骤。长文或复杂译本在图文一体中仍须逐字复验，若失败按有界修正流程处理，不静默切回本地。

## 2. 提示词结构（按路线分支）

建议按以下顺序：

```text
Use case:
Asset type:
Primary request: 用一句话写核心视觉关系
Scene/backdrop:
Style/medium:
Composition/framing: 主视觉关系及文字共存条件，不预设整套文字布局
Lighting/mood:
Color palette:
Materials/textures:
Constraints:
Avoid:
```

`Constraints` 至少包含：

- 默认：准确六组文案＋专业指引；不添加额外文字；no watermark。不得出现 no text / text-free 等冲突要求。
- 本地路线：no text / letters / numbers / logo / watermark，明确排版安全区。
- 不出现禁止直画项
- 把本轮表达边界写进实际提示词：默认不出现人物主体、人物表情／活动演示或拟人情节；具象静物与空间关系不禁用。有用户明确例外时只放宽已授权部分，不笼统删除反直译约束。
- 按本节留白要求承托所有文字，文字与画面共存且可读；默认不固定文字区域、空白比例或坐标。

`Avoid` 只列对本方案有理由排除的内容：

- 与内容不符的常见俗套
- 本轮决定回避的表达惯性；近期媒介或色彩不自动禁用
- 会把画面推向宣传画、鸡汤海报或廉价古风的元素

## 3. 中文准确性

默认模型自主设计，但不自主改写文案。逐字抄读六组，允许换行与空白变化，不允许漏字、增字、替字、错误标点或错日期／星期。独立原始结果必须逐组给 `observed_text` 与 `matches`，不得只勾“文案正确”。

以下源代码与字体加载要求仅适用于本地路线：

优先使用 SVG + Sharp、Canvas 或现有设计源文件。排版代码必须可重跑，方便局部修改。

检查：

- 字体真实存在并覆盖中文字符。
- 正文标点与核验版本一致，不为排版润色或统一标点；辅助文案用规范中文标点。
- 作者和作品名与核验版本一致，无漏字或错误书名号；必要的繁简转换明确记录，不把查重标准化后的文字拿来排版。
- 行距匹配句子节奏。
- 文字不贴边、不跨越高噪声纹理。
- 强调色只突出真正的语义核心。

在原尺寸下分别读正文、出处、宜、忌，记录每组实际结果；日期与星期另核对。文字留白区内存在深浅变化时检查整个词组，不以起点或平均底色代替判断。白字在浅底消失即失败；优先调整留白区内的落位、字色或留白底色，再复查整体层级。分数和“已检查”勾选不能抵消任一必需文字不可读。

不要用手工像素覆盖修改文字；回到可编辑排版源。

## 4. 信息层级

必选：

1. 日期与正确星期。
2. 正文。
3. 来源。
4. 宜与忌。

可选：

- 今日练习。
- 系列编号。
- 极短栏目名，如“今日摘句”。

额外文案仅在用户明确要求时纳入生产合同，不由模型自行添加。默认六组文案之外不加栏目标题或签名。

正文必须是第一视觉层级，但不等于把每个字都放到最大、最重。位置、空白、对比、字重和图文体量共同决定阅读顺序；根据本句决定整体均衡或局部强调，强调色不是必选。日期可以突出，但不得压过正文。来源和宜忌要读清并自然接续，不挤成另一块同样沉重的标题。

## 5. 字体选择

**字体范围开放，不设固定白名单。**宋／明朝、黑体、楷体、圆体、手写及其他可用字体都可探索；字体目录只是资源，不是封闭候选池。先确定本句声音与布局职责，再选择实际字形，不能按时代、国别、体裁或抽象情绪直接套字体类别。

默认由生图模型选择，不先从本地字体目录给它候选表或偏好白名单。本地路线的选型顺序：

1. 查看本地可用字体与字重，不默认沿用上次字体组合。
2. 用本句的实际字词和标点试排，观察字面大小、中宫、笔画、字重及停顿是否呈现预期声音；记录具体字形或阅读证据，而不只写“宋体有文学感”。
3. 放回完整小样，在原尺寸检查清晰度与图文体量；字体名称、装饰性和字重数量不能代替实际结果。
4. 缺字、资源不可用或确实不适配时，扩展到其他可用字体。检查实际加载的字体，不能静默回退后仍用原选型理由。另行下载或安装须遵守环境和授权边界，不把每日换字体或安装字体当流程目标。

同一字体连续使用可以成立，关键是本句和构图是否支持；小字、细字、书法和大字都不天然更有设计感。红色方块、横向装饰线和“取意自”仍按用户禁项处理，不借开放字体选择解除这些约束。

### 整体设计验收，不以可读代替

在最终有字卡片的原尺寸中检查：

- **阅读节奏 `reading_rhythm`**：实际会在哪里停顿、重读？换行、间距或强调是否割裂本句、让普通词变口号？指出具体词组／行与效果，不只写“节奏自然”。
- **图文关系 `image_text_relationship`**：先指出正文和辅助文字分别由哪处设计留白承托，和图像主体、细节及纹理之间有怎样的视觉间隔；直接压在图像上、像摄影作品加字幕，即使可读也 revise。再指出文字块与图像的轴线、边界、体量、间隔或方向怎样相互支持；留白存在本身不足以证明整体性，简洁分区可以因真实的平衡或对照成立。
- **层级与呼吸 `hierarchy_and_breathing`**：第一眼到底落在哪里，之后怎样读？日期、出处或宜忌是否形成抢眼的第二标题块？指出实际区域、间距和主次，不只写“正文最大”；辅助信息可读是并列硬条件。
- **字体适配 `font_fit`**：不用预案解释，仅根据原句与成品，说出实际感到的声音及具体字形／字重依据；是否把温和交流读成宣言，把舒缓句读成硬口号，或发生其他有文本依据的偏移？“文学所以宋体”“字体清楚”不足以通过。

每项给出具体观察；本地选型理由保存于 `layout.font_rationale`、`layout.line_break_rationale`，默认路线可留空，不事后编成前置设计。独立观察由对应路线原始 `typography_design_review` 保存，不混写、不另造总分。两条路线都提供四项问题；有语气偏移、错误停顿、主次抢夺或图文脱节即 revise，哪怕字清楚。仅偏好不同不构成返工理由。模型自主设计保留自由，也接受真实失败判定。

设计感不等于花体、拉伸字形、逐字错位、旋转、装饰线、色块或过多字重。简洁、居中、左对齐、宋体和黑体都可成立；依据是本张卡的实际关系，不是必须每天换一套。保留用户已明确的红色方块、横向装饰线和“取意自”禁项。对外仍按四段式理念交付，不追加字体参数或内部比较报告。

最近3–5张同时比较文字块结构、字重、换行节奏、日期处理和图文骨架。发现连续重复时重新问本句是否真的需要它，而非机械换字体或版式。“这张字小”只触发该张可读性修订，不推导出以后全用大粗字；“这张很好”也不把其字号、强调色或布局变成默认模板。

## 6. 宜忌

宜忌负责把文字转成当天可执行的倾向：

- 每项尽量 6–12 个汉字。
- 语气平等、克制，不训诫。
- 与正文同源，但不重复正文。
- 不伪装成作者原话。
- 不做玄学预测。
- 宜写可做之事；忌写需要觉察的惯性。

示例：

```text
宜｜做一件能做的事
忌｜让消沉替自己决定
```

## 7. 局部修改

用户指出重叠、颜色、文案或元素问题时：

1. 识别准确目标。
2. 本地路线修改排版源／底图；图文一体使用 imagegen 局部编辑，保留未指定画面及全部准确文案，不手工覆字。
3. 保持未指定区域不变。
4. 新建版本文件，除非用户明确要求覆盖。
5. 重新回读整张图，不只查看局部截图；登记新的排版版本，使旧版可读性结果失效。

若装饰元素已经烘焙进底图，可局部修复背景；不要因此重生整张图造成风格漂移。

只改字号或落位时继承未变原文、历史和概念。本地路线无需重生底图，无字输入未变可继承第一阶段；默认路线局部编辑后的PNG是新生成版本，全部文字与整体关系重新审核。不能将旧卡修改后沿用旧回执。默认同概念最多初版＋一次针对性修正，继续失败停下说明缺口，请用户决定继续或换路线；这不是最终质量豁免。

## 8. 输出与回读

- 输出 PNG，尺寸适合移动端竖屏。
- 在设计记录中填写画布宽高，完整解码最终 PNG 后比对；默认保留生成PNG原字节并绑定准确文案及审核，本地才绑定排版源，不沿用其他版本的审核。
- 保存到当前项目规定的用户输出目录。
- 以原始分辨率回读。
- 最终回复展示图片、提供文件链接、说明内容和艺术方向。
- 若浏览核验来源，在来源说明附近提供链接。
- 生成模式、提示词与审核细节留在内部；对外只发主 Skill 规定的最终图片与四段式设计理念。
